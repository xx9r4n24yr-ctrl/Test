Моя ферма — Telegram Mini App prototype.

Файлы:
- index.html — главный файл запуска
- styles.css — адаптивный интерфейс
- game.js — логика игры, экономика, экраны, Telegram WebApp API
- assets/avatar.svg — аватар по умолчанию

Как запустить локально:
1. Откройте index.html в браузере.
2. Для Telegram Mini App загрузите папку на HTTPS-хостинг.
3. Укажите URL в BotFather → Menu Button / Web App.

В игре есть:
- главный экран фермы;
- животные: курицы, коровы, свиньи, овцы;
- уровни построек и вместимость;
- поля: пшеница, кукуруза, морковь, тыква;
- рынок, заказы, ежедневная награда;
- адаптация под мобильные экраны;
- Telegram WebApp expand + disableVerticalSwipes.
